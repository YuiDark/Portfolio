# 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/WarriorOGZz/Premium-Portfolio-Page..git
```

### Navigate

```bash
cd Premium-Portfolio-Page.
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

---

# 📦 Production Build

```bash
npm run build
```

### Preview

```bash
npm run preview
```
