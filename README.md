# Dark Portfolio

Light-first portfolio for Dark. Purple accent, Outfit type, and a JavaScript stack.

## Config

Edit `src/config.ts`.

- `profile` — name, role, email, bio
- `stack` — JavaScript, TypeScript, Node.js, React, Next.js, Vite, Tailwind CSS, Git
- `projects` — work cards
- `theme.defaultMode` — `"light"`
- `theme.font` — Outfit
- `music.src` — track in `public/`

Python is not part of this site.

## Run

```bash
npm install
npm run dev
```
